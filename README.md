# Bare-bones-Programmable-ws2812b-LED-Driver
compact programmable led driver with buttons and potentiometers to change and edit the state of the ws2812b addressable LEDs.

## Goal
I originally built this project using an Arduino Nano on a breadboard and transferred it to a prototype solder board to be more compact and cleaner overall.
The next step of this project is to turn that prototype into a compact, polished PCB while keeping the same basic functionality.
